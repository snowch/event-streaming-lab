Adapted from snowch/postgresql-lab's learning-design skill.
State practical questions, observable goals and prerequisites. Define new terms before applying them. Use inspectable inputs, optional prediction prompts, actual execution, a change-one-thing task and an independent transfer question. Provide progressive hints and a worked explanation. Run every published example from the documented initial state. Distinguish built-in operators from authored teaching policies and genuine broker guarantees. Cite primary sources and record executed evidence and limitations in docs/review.md. No additional approval is required.
